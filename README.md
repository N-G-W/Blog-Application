# Blog-Application
This is a simple blog application that uses Node.js, Express.js and Ejs. The users can add content both text and images. The styling is done in vanilla css. Although not connected to a database, some persistance exists due to writing to file. Here is the preview:

## Setting up
1. Install npm packages
```
  npm install
```

2. Start server
```
  nodemon index.js
```
